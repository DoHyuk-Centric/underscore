# 인기 섹터 구현 계획

## 목표

KRX 시리즈 일별시세정보를 이용해 전 영업일 기준으로 상승률이 높은 섹터를 제공하고, 프론트엔드의 인기 섹터 목록에 표시한다.

## 데이터 기준

- 사용 API: KRX 시리즈 일별시세정보
- 엔드포인트: `https://data-dbg.krx.co.kr/svc/apis/idx/krx_dd_trd`
- 인증 환경변수: `KRX_OPEN_API_KEY`
- 인기 순위 기준
  1. 등락률(`FLUC_RT`) 내림차순
  2. 등락률이 같으면 거래대금(`ACC_TRDVAL`) 내림차순
- 기준일: 조회 가능한 최근 영업일
- 노출 개수: 최대 10개

## 전체 흐름

```text
KRX 지수 원본 데이터
→ 섹터지수 필터링
→ 숫자 변환
→ 등락률·거래대금 정렬
→ 상위 10개 선정
→ 서버 캐시
→ API 응답
→ 프론트 스키마 검증
→ 인기 섹터 목록 렌더링
```

## 구현 시 주의사항

- `IDX_CLSS`의 실제 응답값을 확인하기 전에는 필터 문자열을 추측해서 고정하지 않는다.
- KRX API의 숫자 필드는 문자열로 전달되므로 비교 전에 반드시 숫자로 변환한다.
- 단순 거래대금 순위는 대형 종목이 포함된 섹터에 편향될 수 있으므로 기본 순위는 등락률을 사용한다.
- 주말과 공휴일에는 전날 데이터가 없을 수 있으므로 이후 최근 영업일 조회 보완을 검토한다.
- 초기 구현에서는 메모리 캐시를 사용하고, 서버가 여러 대로 늘어날 때 Redis 같은 외부 캐시를 검토한다.
