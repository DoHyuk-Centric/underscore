# 밑줄

> 매수 버튼을 누르기 전에 이유를 적게 하고, 팔고 나면 그 이유가 맞았는지 알려주는 모의투자 서비스

**밑줄**은 결과만 남는 투자 경험 대신, 투자 판단의 근거와 결과를 함께 돌아보게 하는 앱인토스 미니앱입니다. 수익률 자체보다 “왜 이 종목을 선택했는가”를 기록하고 검증하는 경험에 집중합니다.

## 왜 만들었나요?

초보 투자자는 매수 이유를 충분히 정리하지 못한 채 거래하기 쉽습니다. 이 경우 수익과 손실 어느 쪽의 결과가 나와도 다음 판단에 활용할 학습이 남지 않습니다.

밑줄은 매수 전에 근거를 반드시 기록하게 하고, 매도 후에는 그 근거와 실제 결과를 대조한 리뷰를 제공합니다. 공시와 시세를 판단 재료로 연결해, 근거 있는 투자 습관을 만드는 것이 목표입니다.

## 핵심 경험

```text
종목 탐색 · 공시 확인
        ↓
매수 전 근거 입력 (필수)
        ↓
가상 매수 · 보유 · 평가손익 확인
        ↓
매도
        ↓
근거와 결과를 대조한 AI 거래 리뷰
        ↓
밑줄 기록에 누적
```

- **근거 없는 주문 방지**: 매수마다 근거를 남깁니다. 추가 매수도 별도의 판단으로 기록합니다.
- **lot 단위 기록**: 매수 1건을 하나의 lot으로 관리해, 각 근거가 어떤 결과로 이어졌는지 1:1로 확인합니다.
- **AI 판단 리플레이**: 손익·보유 기간·벤치마크 대비 성과·공시 등 계산 가능한 사실을 먼저 만들고, AI는 이를 바탕으로 회고를 문장화합니다.
- **공시 학습**: DART 공시를 이벤트 카드와 쉬운 설명으로 제공해 판단의 재료로 활용합니다.

## 기술 선택

### Frontend — React + Vite

밑줄의 주 사용 환경은 토스 앱 안의 WebView이며, 차트·가상 주문·근거 입력처럼 지속적인 상호작용이 중심입니다. React의 클라이언트 UI 모델은 이러한 화면을 구성하기에 적합합니다.

Vite는 앱인토스 WebView 미니앱에 필요한 정적 결과물을 단순하게 만들고 빠르게 배포할 수 있게 합니다. 서버 렌더링과 SEO에 강점이 있는 Next.js는 공개 콘텐츠 중심 서비스에 더 적합하므로, 현재 MVP의 핵심 요구에는 도입하지 않았습니다.

- 앱 환경: 앱인토스 WebView SDK
- 디자인 시스템: TDS Mobile / TDS Mobile AIT
- UI 상태: Zustand
- 데이터 경계 검증·공유 타입: Zod

### Backend — NestJS + Fastify

백엔드는 인증, 가상 주문, 시세 수집, SSE 전달, 공시 수집, AI 리뷰 등 책임이 다른 기능을 함께 다룹니다. NestJS의 모듈 구조와 의존성 주입, 가드·예외 처리 체계는 기능이 늘어나도 경계를 명확하게 유지하게 합니다.

HTTP 엔진으로는 Fastify 어댑터를 사용합니다. 초기에는 여러 서비스로 나누지 않은 **모듈형 모놀리스**로 시작해, 거래 정합성과 빠른 개발 속도를 함께 확보합니다.

- 거래 원장: PostgreSQL + Drizzle ORM
- 실시간 전달: SSE
- 시세 캐시: 백엔드 프로세스 메모리
- 확장 시점: 다중 인스턴스·공용 캐시·Pub/Sub이 필요할 때 Redis 검토

## 아키텍처

```text
앱인토스 WebView (React + TDS)
          │ HTTP / SSE
          ▼
NestJS + Fastify
 ├─ Auth / Trading / Portfolio
 ├─ Market Data / Price Stream
 ├─ Disclosure / Review
          │
          ├─ PostgreSQL
          ├─ DART Open API
          └─ 시세 데이터 소스
```

민감한 API 자격 증명은 클라이언트에 노출하지 않고 서버 환경 설정에서만 보관합니다. 가상 매수·매도는 실제 증권 주문 API를 호출하지 않으며, 서버와 데이터베이스 트랜잭션으로 확정합니다.

현재 MVP에서는 제3자 시세 제공 제약을 고려해 주문 가격을 사용자가 직접 입력하는 방식을 우선 적용합니다. 실시간 시세 연동은 약관과 데이터 소스 조건을 충족하는 방향으로 후속 검토합니다.

## 프로젝트 구조

```text
apps/
  web/       React + Vite 기반 앱인토스 WebView 클라이언트
  api/       NestJS + Fastify 백엔드
packages/
  shared/    프론트엔드·백엔드 공유 타입과 Zod 스키마
docs/        제품, 기능, 데이터 모델, 아키텍처 설계 문서
design/      TDS 기반 UI 프로토타입
```

## 시작하기

```bash
pnpm install

# Web
pnpm dev:web

# API
pnpm dev:api

# 전체 빌드 및 린트
pnpm build
pnpm lint
```

## 안내

밑줄은 투자 교육과 회고를 위한 모의투자 프로젝트입니다. 특정 종목 추천이나 매수·매도 신호를 제공하지 않으며, 실제 자금이나 증권 계좌를 연동하지 않습니다.
